# Shared sources

Place sources intended for version control here. Describe their precise relevance in `../context.md` and add bibliographic entries to `../references.bib` where applicable. Use links for large files or sources that should not be redistributed.

Put private sources in `../private/` (create locally; ignored by Git). Describe how collaborators can obtain a source without exposing private content. Mathematical source annotations may be `.tex` fragments using the shared preamble and definitions; do not maintain conflicting copies of definitions.
