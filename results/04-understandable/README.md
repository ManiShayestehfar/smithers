# 04 — Understandable

This is formal, paper-ready mathematics: precise statements, complete proofs, consistent definitions, and a clear explanation of each result's role. It is not a folder for informal summaries.

Retain stable labels and provenance comments. Include fragments through `main.tex` in dependency order or transfer them into a paper with the necessary definitions, macros, and bibliography. Remove research placeholders and visible gap notices only after resolving them. Explicitly open problems remain labelled as open.

Substantive revisions require renewed human review; return a result to proof development if a gap appears.
