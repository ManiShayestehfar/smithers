# Computations

Add scripts, notebooks, formal verification projects, data, and small reproducible artifacts here as needed. No language or toolchain is prescribed.

For each computation, record its associated result ID, exact inputs, run command, dependency versions, random seed if applicable, and the interpretation and limits of its output. Record human/model contributions in comments or an adjacent note using the same fields as `templates/result.tex`.

Mathematical claims and arguments belong in the result files. Link computational evidence by repository-relative path. Distinguish experiments from exhaustive verification and certified proofs. Keep shared notation consistent with `definitions.tex`.

`code/generated/` and `code/data/private/` are ignored. Preserve small evidence needed for review in a tracked location such as `code/evidence/`, or document its reproducible regeneration. Do not rely on ignored outputs as the only evidence for a claim. Add a dependency manifest only after choosing your tools.
